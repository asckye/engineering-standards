# 大屏

> **要点** 大屏要在远处一眼看懂，并且长期无人值守地运行。数据过期必须看得出来，出错能自己恢复。

状态：**草稿 0.1**。这里的规则都是建议，还没有项目验证过。本文件只用 SHOULD，等项目验证后再定哪些升为 MUST。

**适用：** 在车间、调度室、展厅等场所长期显示数据的大屏和看板。

**不适用：** 操作员要在画面上操作设备的软件，按[上位机规范](../hmi/README.md)。

**同时采用：** [通用规范](../general/README.md)；用浏览器实现时加 [Web 规范](../web/README.md)，用桌面程序实现时加[桌面与本机软件](../desktop/README.md)。大屏只读且按固定分辨率设计，所以 `WEB-03` 的键盘要求、`WEB-04` 的页面加载预算、`WEB-05` 的响应式要求和第 21 节的键盘规则不适用；`WEB-13` 的人工登录改按 `DSH-19`。

**等级：** 长期无人值守不等于 L 级。大屏只展示时通常是 M 级；操作决策依赖它或受监管时再按 L 级。

## <a id="dsh-scope"></a>范围

- **SHOULD** `DSH-01` 大屏只读，不提供写入目标或设备的操作。需要操作时转到有权限和审批的系统。
- **SHOULD** `DSH-02` 写明观众、观看距离和要回答的问题。每个指标写明口径、单位、数据来源和更新周期。

## <a id="dsh-layout"></a>显示与布局

- **SHOULD** `DSH-03` 写明目标分辨率、屏幕比例和拼接方式。按设计分辨率等比缩放，不出现滚动条和被裁切的内容。
- **SHOULD** `DSH-04` 关键数字和文字避开拼接缝。
- **SHOULD** `DSH-05` 最小字号按观看距离确定，并在真实屏幕上核对。对比度按 `UI-10`，状态不只靠颜色（`UI-13`）。
- **SHOULD** `DSH-06` 一屏一个主题。轮播时每页停留足够长，有新告警时暂停轮播或跳到告警。
- **SHOULD** `DSH-07` 颜色只表达状态和分类，告警色不作他用（`IND-22`）。

## <a id="dsh-data"></a>数据

- **SHOULD** `DSH-08` 每个区块能看到数据时间。超过更新周期就明确标为过期，不静默显示旧值（`IND-09`）。过期按服务器时间判断。
- **SHOULD** `DSH-09` 区分“没有数据”“数据为零”和“取数失败”。
- **SHOULD** `DSH-10` 前端不直连生产数据库或设备，经只读的聚合接口取数。聚合层缓存并限流，大屏刷新不影响生产系统。数据从生产网单向流出，经隔离区（`IND-35`）。
- **SHOULD** `DSH-11` 指标只在后端算一次，大屏和报表用同一口径（`P-09`）。
- **SHOULD** `DSH-23` 核对指标的边界：班次和日切换、夏令时、不完整的周期，并和来源报表对账。
- **SHOULD** `DSH-12` 时间按 UTC 存储，按现场时区显示（`I18N-03`）；数字格式和单位全屏一致。

## <a id="dsh-running"></a>长期运行

- **SHOULD** `DSH-13` 断线后按指数退避重连，恢复后自动刷新，不需要人到现场操作（`IND-05`）。
- **SHOULD** `DSH-14` 浸泡测试至少 72 小时：内存、定时器、连接数和图表实例数平稳；切页时释放图表和订阅。
- **SHOULD** `DSH-15` 展示机开机自启，防止误操作，崩溃后自动恢复；关闭系统更新、休眠、通知和崩溃提示，时钟同步。版本和运行状态不到现场也能查看。
- **SHOULD** `DSH-22` 能发现画面冻结：屏上有走动的时钟，并由外部看门狗检查心跳。渲染挂起时，过期判断也会一起停住。
- **SHOULD** `DSH-16` 动效克制，不持续闪烁（`UI-31`）。屏幕类型容易残影时，固定内容定时位移或切换。

## <a id="dsh-performance"></a>性能

- **SHOULD** `DSH-17` 在实际展示机上设帧率和更新延迟预算。按数据更新周期批量更新，不按帧重绘全部图表。

## <a id="dsh-security"></a>安全与隐私

- **SHOULD** `DSH-18` 按摆放场所评估屏上内容，敏感数据和个人数据脱敏或不显示。
- **SHOULD** `DSH-19` 展示端用专门的只读设备凭据，可以撤销；凭据不放在 URL 里，前端不放其他密钥（`WEB-08`）。

## <a id="dsh-testing"></a>测试

- **SHOULD** `DSH-20` 在目标分辨率下做截图回归，覆盖极端数据：超长名称、很大的数、空数据和全部告警。
- **SHOULD** `DSH-21` 上线前在真实屏幕和实际观看距离下走查。

## <a id="dsh-checklist"></a>发布清单

- [ ] 目标分辨率和拼接方式下显示正确，没有滚动条和裁切。
- [ ] 断网、后端重启和数据过期时显示正确，恢复后不需要人操作。
- [ ] 浸泡测试通过，内存和连接数平稳。
- [ ] 真实屏幕和实际距离下走查通过。
- [ ] 屏上内容按摆放场所核对过，展示端只读。
