# <a id="changelog"></a>规范变更记录

| 版本 | 日期 | 变化 |
|---|---|---|
| 3.0 | 2026-11-05 | 做成 Agent Skills 和 Claude Code 插件：每部分一个 skill，文件移到 `skills/`，每类项目有最小清单。小工具有了自己的做法；0.2 为只有维护者自己用、不发布的 S 级小工具按条件放宽 `DOC-06` 和 `P-14`，所以升主版本。规则条目的编号、文字和级别没有变。详见仓库的 [CHANGELOG](../../../../CHANGELOG.md)。 |
| 2.1 | 2026-11-05 | 开发周期补到交付、运行和退役（第 27–29 节）；新增隐私、密码学、发给外部模型的数据、并发、依赖、发布和法规的规则，以及标准对照；统一定级标准（0.7），按标准提高了一批规则的级别；修正 S 级和未标等级规则的关系；规则改为平台中立的写法；夜间检查改称完整检查。详见仓库的 [CHANGELOG](../../../../CHANGELOG.md)。 |
| 2.0 | 2026-11-05 | 按项目类型重组：通用规范留在 `general/`，各类项目专属规则放在根目录各自的文件夹；领域 A、C 由 `mcp/` 取代；新增 `vision/`、`dashboard/` 草稿；详见仓库的 [CHANGELOG](../../../../CHANGELOG.md)。 |
| 1.1 | 2026-11-02 | 精简：MUST 由 456 条减为 150 条，每条 MUST 附一行理由，其余降为 SHOULD，或合并、删除（规则总数 491 → 396）；界面一章改为通用默认值（行高按产品选 36 或 44、撤销与审批规则、审批按钮不设访问键），项目的取舍记在自己的 ADR 中；合并门目标约 15–20 分钟，项目可更严；执行映射表按 MUST 重写。首次进入仓库时的文字修正见仓库的 [CHANGELOG](../../../../CHANGELOG.md)。 |
| 1.0 | 2026-11-02 | 首版：项目通用部分 0–26、最小必做清单、领域规范 A–F、语言附录 L1–L3、模板、术语表。 |
