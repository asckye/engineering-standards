# <a id="pd"></a>领域 D：桌面应用

> **要点** MVVM、界面线程不做 IO、按用户的数据位置、可回滚的更新；界面规则见第 21 节。

适用于 Windows WPF、WinUI，以及适用时的 Electron、.NET MAUI。第 21 节全部适用。

- **SHOULD** `DSK-01` MVVM：视图只做绑定和呈现；视图模型不引用控件类型；业务逻辑在视图模型之外，可以不启动界面测试。
- **MUST** `DSK-02` 界面线程只更新界面对象，跨线程经调度器；界面线程不做 IO、不阻塞等待；长操作显示进度并可取消。
  - 理由 · 界面线程上的 IO 会冻结界面。
- **SHOULD** `DSK-05` 需要单实例时用当前用户范围的命名互斥量；第二个实例把参数转交给已运行的实例后退出。
- **SHOULD** `DSK-07` [M+] 安装程序与自动更新符合 PKG 与 MIG-05：按用户安装、校验哈希、保留上一版本用于回滚；更新时不强制结束正在写入的进程。
- **SHOULD** `DSK-08` [M+] 可执行文件和安装包用代码签名证书签名（带时间戳）；未签名时在发布说明中说明，并提供 SHA-256。
- **MUST** `DSK-09` Electron：渲染进程开启 `contextIsolation` 与 `sandbox`，关闭 `nodeIntegration`，经 preload 暴露最小 API，设置 CSP，不加载远程内容执行代码。
  - 理由 · 渲染进程被注入后会获得系统权限。

## <a id="pd-checklist"></a>D.1 桌面发布清单

- [ ] 1024 × 640、200% 缩放、中英文、浅色/深色/高对比渲染检查通过。
- [ ] 标准用户在干净机器上安装、首次运行、升级、回滚、卸载各一遍。
- [ ] 单实例、崩溃处理、诊断包导出可用。
- [ ] 签名与哈希齐全；SmartScreen 提示已在发布说明中说明（未签名时）。
