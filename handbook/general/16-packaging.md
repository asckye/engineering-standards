# <a id="packaging"></a>16 打包与安装

> **要点** 按用户安装、不要管理员；卸载保留数据；包内容由清单决定。

- **SHOULD** `PKG-01` 默认按用户安装，不需要管理员：程序在 `%LOCALAPPDATA%\Programs\<Product>`（或用户选择的目录），数据在 `%LOCALAPPDATA%\<Product>`；运行时不写程序目录之外的系统位置。
- **MUST** `PKG-04` 卸载撤销注册、删除程序，保留用户数据并说明位置；删除数据是单独的、需要确认的操作。
  - 理由 · 卸载时删除用户数据无法挽回。
- **MUST** `PKG-07` 包内容由一份清单决定，由检查核对；不含开发源码、密钥、厂商 SDK 和测试数据。
  - 理由 · 防止把密钥、开发文件或厂商 SDK 发出去。
- **SHOULD** `PKG-08` [M+] 预发布交给测试者时附：测试清单（按“未验证”清单编号）、反馈模板（Issue 模板，填写清单编号、版本、环境）；反馈先记入反馈台账，复核后再写入真机台账。
