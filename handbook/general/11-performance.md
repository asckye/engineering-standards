# <a id="perf"></a>11 性能

> **要点** 只在关键路径上优化并给出前后计时；批量调用，源头分页。

- **SHOULD** `PERF-01` 只优化关键路径（对目标软件或设备的调用、周期采集、界面线程、请求热路径），并在 PR 中给出同一台机器上改动前后的计时。
- **SHOULD** `PERF-02` 对目标和设备的调用成批进行：API 允许时一批一次调用，避免跨进程的 N+1 调用。
- **SHOULD** `PERF-03` 大列表在源头分页和过滤；结果有大小预算，超出时分页或给出句柄。
- **SHOULD** `PERF-04` 缓存只存不可变或限定快照的数据，键包含版本或绑定标识，写入时失效；不跨请求缓存厂商对象。
