# <a id="dod"></a>23 完成定义

> **要点** 任务、合并、发布各有一张完成清单；没过清单就不算完成。

## <a id="dod-task"></a>23.1 任务完成

- [ ] 代码、测试、生成文件和文档在同一个任务中更新；生成文件由生成器产出。
- [ ] 主要行为和相关失败路径有测试；缺陷修复有回归测试。
- [ ] 零新增分析器警告；格式化通过。
- [ ] 契约变化已重新生成快照并逐项说明；破坏性变化写入迁移表。
- [ ] 用户可见的变化写入 CHANGELOG `Unreleased`。
- [ ] 依赖目标的新行为加入实机核对清单，或在台账中标 `NOT RUN`。

## <a id="dod-merge"></a>23.2 合并完成

- [ ] 评审通过，阻止项（REV-05）全部解决。
- [ ] 在变基后的提交上通过合并门。
- [ ] 任务分支已删除；交接文档和任务状态已更新 [M+]。

## <a id="dod-release"></a>23.3 发布完成

- [ ] 发布证据有效（[M+] 最近一次夜间检查通过且之后无失败）。
- [ ] CHANGELOG 版本条目、发布说明、“未验证”清单与版本号一致。
- [ ] 资产附 SHA-256（[M+] 加 SBOM 与来源证明）。
- [ ] 维护者已确认；发布后更新交接与发布记录。
