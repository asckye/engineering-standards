# 本机运行的软件

> **要点** 软件跑在用户或现场的机器上时，数据默认不离开这台机器，本机通道和 HTTP 也要防同机其他用户和网页。

这些规则用于在用户或现场机器上运行的软件，包括桌面应用、MCP 服务、上位机和视觉软件；这类软件直接处理用户自己的文件。服务端和浏览器应用按 [Web 规范](../web/README.md)。

## <a id="security-ipc"></a>6.6 本机管道与 HTTP

- **MUST** `SEC-14` 命名管道：名称由当前用户 SID 和安装路径派生；受保护的 DACL 只授予当前用户；拒绝远程客户端；双方核对对方 SID，需要时核对对方映像路径；帧有大小上限，未知字段和重复字段拒绝。
  - 理由 · 防止同机其他用户或进程冒充对端。
- **SHOULD** `SEC-15` HTTP 默认只监听 `127.0.0.1`；局域网访问只绑定人选择的具体 IP，防火墙只放行指定来源；明文 HTTP 只在私有网络中使用，作为剩余风险写入威胁模型。
- **MUST** `SEC-16` HTTP 认证：每个请求带 `Authorization: Bearer`，密钥至少 24 字节随机数，恒定时间比较；失败只回 401，同一来源连续失败后限流；健康检查端点只返回版本等非敏感信息。
  - 理由 · 防止未认证的网络访问。
- **MUST** `SEC-17` 校验 `Origin` 头（不在允许列表中回 403，允许列表默认空）和 `Host` 头，防 DNS 重绑定。
  - 理由 · 防止 DNS 重绑定攻击本机服务。

## <a id="local-data"></a>数据不外传

- **MUST** `DAT-06` 没有人的明确同意，任何数据都不离开这台电脑：不自动上传日志、崩溃转储或使用统计（[第 22 节](diagnostics.md#diag)）。检查更新只发送版本请求，不发送用户数据。
  - 理由 · 未经同意外传数据违反用户信任和法规。

## <a id="local-files"></a>用户文件

- **MUST** `DAT-02` 覆盖或删除用户数据前备份：复制到新建的带时间戳的目录，核对副本（大小、哈希或对象数），备份失败就不执行；备份路径写入结果和审计；备份不自动删除。
  - 理由 · 覆盖或删除后无法恢复用户数据。
- **MUST** `DAT-03` 修改用户的配置文件（例如 AI 客户端配置）前，先展示将写入的内容和备份位置，备份原文件后再写入。
  - 理由 · 防止用户的配置被覆盖丢失。
- **SHOULD** `DAT-05` 每类本地数据有保留规则并写在用户文档中：运行日志按份数或天数轮转；导出句柄、临时文件有过期时间；审计和备份不自动删除，由人清理。

## <a id="local-privilege"></a>权限

- **SHOULD** `SEC-26` 产品以普通用户权限运行和安装；只有确实需要的步骤（防火墙规则、URL ACL、加入厂商要求的用户组）单独提权，并向人说明原因。

## <a id="local-dirs"></a>数据目录

- **SHOULD** `CFG-04` 数据目录按用户：优先显式指定的目录，其次安装目录下可写的 `data`，否则 `%LOCALAPPDATA%\<Product>`；显式指定的目录无效时立即报错，不静默回退。
