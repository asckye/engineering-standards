# <a id="packaging"></a>16 打包与安装

> **要点** 按用户安装、不要管理员；卸载保留数据；更新可回滚。

- **SHOULD** `PKG-01` 默认按用户安装，不需要管理员：程序放在用户目录（Windows 是 `%LOCALAPPDATA%\Programs\<Product>`）或用户选择的目录，数据放在系统的用户数据目录；运行时不写程序目录之外的系统位置。
- **MUST** `PKG-04` 卸载撤销注册、删除程序，保留用户数据并说明位置；删除数据是单独的、需要确认的操作。
  - 理由 · 卸载时删除用户数据无法挽回。
- **MUST** `MIG-05` [M+] 更新器：核对发布者签名、哈希和版本号，签名私钥不放在更新服务器上；暂存后原子替换，保留上一版本用于回滚；失败自动回滚；不动用户数据；正式安装不收预发布，除非用户选择。
  - 理由 · 坏的更新无法回退会让用户停工。
