# <a id="checklists"></a>26 通用检查清单

> **要点** 发布、实机验证、上线交付和退役四张清单；PR 自查清单在模板 T.5 中。

## <a id="checklist-release"></a>26.1 发布

- [ ] 维护者确认版本号与范围；发布期间不改代码。
- [ ] 发布证据有效；依赖扫描无高危 [M+]；安全复核已完成 [M+]。
- [ ] CHANGELOG、发布说明、支持矩阵、“未验证”清单已生成并核对。
- [ ] 包内容与清单一致；SHA-256 齐全（[M+] 加 SBOM 与来源证明）。
- [ ] 预发布标为预发布、不设为最新；附测试清单与反馈模板。
- [ ] 支持政策已写入 README（EOL-01）。

## <a id="checklist-real"></a>26.2 实机验证

- [ ] 只用一次性项目或测试台；导出与临时文件写到产品的数据目录，不放桌面。
- [ ] 记录目标版本（完整构建号）、操作系统、许可、日期、执行人。
- [ ] 每项写结果和证据位置；失败附诊断编号；未跑的写 `NOT RUN`。
- [ ] 结果先进反馈台账，复核后写入真机台账；示例与文档按实测更新。
- [ ] 凭据和端点令牌不打印、不复制进记录。

## <a id="checklist-delivery"></a>26.3 上线交付

- [ ] 验收标准由接收方确认，验收记录完整；S1 问题已解决，其他遗留问题有负责人和期限（ACC-01、ACC-02）。
- [ ] 交付内容齐全，在干净的机器上走过一遍（ACC-04、ACC-05）。
- [ ] 交付配置中没有临时账号和默认口令，调试开关和模拟数据源已关闭；账号、密钥、证书和许可证已移交（ACC-06、ACC-07）。
- [ ] 替换在用系统时：切换方案已确认，备份已完成，回退已演练（ACC-08）。
- [ ] 运行责任和运行手册到位；监控和告警能到人（OPS-01、OPS-02、OPS-03、OPS-05）。
- [ ] 备份恢复演练过；会到期的东西已登记（OPS-12、OPS-13、OPS-17）。
- [ ] 数据清单、保留期和删除手段、加密存储到位（DAT-08、DAT-10、SEC-41）。
- [ ] 支持政策已告知接收方；交付台账已更新（EOL-01、ACC-11）。

## <a id="checklist-retire"></a>26.4 退役

- [ ] 维护者已决定并写了 ADR；停止日期已按支持政策通知到用户（EOL-05）。
- [ ] 用户能导出或读出自己的数据，通知期内一直可用（EOL-07）。
- [ ] 还在运行的版本不依赖要关闭的服务，或者已给出替代办法（EOL-08）。
- [ ] 服务端证书、密钥、令牌和服务账号已撤销；端点和定时任务已关闭；代码签名证书没有撤销（EOL-08）。
- [ ] 用户数据和备份已按保留要求删除或归档，并留下记录（EOL-08）。
- [ ] 域名、包名和更新通道仍在自己手中（EOL-09）。
- [ ] 仓库已归档，README 写明状态和替代方案（EOL-10）。
