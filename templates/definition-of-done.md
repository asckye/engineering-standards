# 完成定义：<任务或版本>

> 模板：[通用规范第 23 节](../general/23-definition-of-done.md)。任务、合并、发布、交付各有一张完成清单；没过清单就不算完成。`[M+]` 只对该等级及以上的项目。复制后删去尖括号中的提示和本段。

## 任务完成

- [ ] 代码、测试、生成文件和文档在同一个任务中更新；生成文件由生成器产出。
- [ ] 主要行为和相关失败路径有测试；缺陷修复有回归测试。
- [ ] 零新增分析器警告；格式化通过。
- [ ] 契约变化已重新生成快照并逐项说明；破坏性变化写入迁移表。
- [ ] 用户可见的变化写入 CHANGELOG `Unreleased`。
- [ ] 依赖目标的新行为加入实机核对清单，或在台账中标 `NOT RUN`。

## 合并完成

- [ ] 评审通过，阻止项（REV-05）全部解决。
- [ ] 在变基后的提交上通过合并门。
- [ ] 任务分支已删除；交接文档和任务状态已更新 [M+]。

## 发布完成

- [ ] 发布证据有效（[M+] 要发布的提交通过了完整检查；按夜间运行时，最近一次通过，之后无失败，而且到要发布的提交只有通过合并门的改动）。
- [ ] CHANGELOG 版本条目、发布说明、“未验证”清单与版本号一致。
- [ ] 资产附 SHA-256（[M+] 加 SBOM 与来源证明）。
- [ ] 维护者已确认；发布后更新交接与发布记录。

## 交付完成 [M+]

- [ ] [26.3 上线交付清单](../general/26-checklists.md#checklist-delivery)已通过；偏离 SHOULD 的项写了理由。
