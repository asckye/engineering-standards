# 发布清单：<X.Y.Z>

> 模板：通用规范[任务手册的发布步骤](../general/00c-playbooks.md#play-release)、[26.1](../general/26-checklists.md#checklist-release)、[26.2](../general/26-checklists.md#checklist-real)、[23.3](../general/23-definition-of-done.md#dod-release) 和项目类型的清单 [B.12](../hmi/README.md#pb-checklist)、[D.1](../desktop/README.md#pd-checklist)、[E.6](../web/README.md#pe-checklist)、[F.1](../mobile/README.md#pf-checklist)、[视觉](../vision/README.md#vis-checklist)、[大屏](../dashboard/README.md#dsh-checklist)。发布说明用 [T.7](../general/appendix/t-templates.md#tpl-release)。`[M+]` 只对该等级及以上的项目。复制后删去不适用的小节、尖括号中的提示和本段。

## 步骤

- [ ] 维护者确认版本号和范围；发布期间不改代码（BLD-07）。
- [ ] 核对发布证据：[M+] 要发布的提交通过了完整检查；按夜间运行时，最近一次通过，之后无失败，而且到要发布的提交只有通过合并门的改动。
- [ ] 生成发布说明和“未验证”清单（T.7），核对支持矩阵；[M+] 测过从上一版本升级（`TST-13`），不能直接退回时写明恢复办法（`BLD-12`）。
- [ ] 由发布命令改版本号、打包、算 SHA-256；[M+] 生成 SBOM。
- [ ] 预发布标为预发布、不设为最新；[M+] 附测试清单与反馈模板（PKG-08）；[M+] 能控制范围时分阶段发布（`BLD-11`）。
- [ ] 上传后更新交接文档与发布记录；[M+] 按写明的方式观察（`BLD-11`）。

## 发布核对

- [ ] 维护者确认版本号与范围；发布期间不改代码。
- [ ] 发布证据有效；依赖扫描无高危 [M+]；安全复核已完成 [M+]。
- [ ] CHANGELOG、发布说明、支持矩阵、“未验证”清单已生成并核对。
- [ ] 包内容与清单一致；SHA-256 齐全（[M+] 加 SBOM 与来源证明）。
- [ ] 预发布标为预发布、不设为最新；附测试清单与反馈模板 [M+]。
- [ ] 支持政策已写入 README（`EOL-01`）[M+]。
- [ ] 从上一版本升级测过；不能直接退回时写明了恢复办法（`TST-13`、`BLD-12`）[M+]。

## 实机验证

- [ ] 只用一次性项目或测试台；导出与临时文件写到产品的数据目录，不放桌面。
- [ ] 记录目标版本（完整构建号）、操作系统、许可、日期、执行人。
- [ ] 每项写结果和证据位置；失败附诊断编号；未跑的写 `NOT RUN`。
- [ ] 结果先进反馈台账，复核后写入真机台账；示例与文档按实测更新。
- [ ] 凭据和端点令牌不打印、不复制进记录。

## 发布完成

- [ ] 发布证据有效（[M+] 要发布的提交通过了完整检查；按夜间运行时，最近一次通过，之后无失败，而且到要发布的提交只有通过合并门的改动）。
- [ ] CHANGELOG 版本条目、发布说明、“未验证”清单与版本号一致。
- [ ] 资产附 SHA-256（[M+] 加 SBOM 与来源证明）。
- [ ] 维护者已确认；发布后更新交接与发布记录。

## 上位机：硬件在环 [M+]

- [ ] 真实 PLC 或仿真 PLC 加实际网络拓扑；记录固件版本与接口数据块版本。
- [ ] 拔网线、PLC 停机、重启上位机：状态显示、安全状态、重连、数据缺口记录都正确。
- [ ] 每个操作员写入路径：确认、量程与允许条件拒绝、读回、审计记录；自动写入路径：量程与允许条件拒绝、审计记录。
- [ ] 配置导出后在干净的机器上恢复，版本一致（`IND-40`）。
- [ ] 报警：触发、确认、搁置、恢复、洪流抑制；报警率统计正确。
- [ ] 负载：最大变量数和最短扫描周期下的周期时间与 CPU、内存。
- [ ] 时间同步漂移、时区与夏令时切换下的历史数据和报警时间戳。
- [ ] 角色权限：每个角色只能做允许的操作；审计记录完整。

## 桌面

- [ ] 1024 × 640、200% 缩放、中英文、浅色/深色/高对比渲染检查通过。
- [ ] 标准用户在干净机器上安装、首次运行、升级、回滚、卸载各一遍。
- [ ] 单实例、崩溃处理、诊断包导出可用。
- [ ] 签名与哈希齐全；SmartScreen 提示已在发布说明中说明（未签名时）。

## Web

- [ ] OpenAPI 差异已评审；破坏性变化升版本。
- [ ] Core Web Vitals 与体积预算通过；无障碍自动检查与键盘走查通过。
- [ ] 安全头、CSP、Cookie 属性、CORS 白名单已核对；依赖扫描无高危。
- [ ] 迁移在 staging 演练；回滚步骤可用；备份最近一次恢复演练成功。
- [ ] 仪表盘与告警覆盖新功能；功能开关有到期日。

## 移动

- [ ] 设备矩阵上的冒烟测试通过；离线、弱网、权限被拒绝时的行为正确。
- [ ] VoiceOver/TalkBack 与最大字号下走一遍主要流程。
- [ ] 隐私标签、权限说明文字与实际一致；崩溃报告需同意。
- [ ] 内部测试渠道验证通过；分阶段发布的比例和暂停条件已设定。

## MCP

- [ ] 实机核对清单已更新，未验证的行为写入发布说明（`VER-09`）。
- [ ] 契约快照的差异逐项说明（`VER-02`）；采用 `VER-12` 时已运行 Agent 评测。

## 视觉

- [ ] 验收指标在真实产品和光照下测过，结果已记录；`VIS-03`、`VIS-28` 的评估已完成，样本量和置信度已记录。
- [ ] 回归图像集通过，漏检率和误检率不高于门禁。
- [ ] 回放或仿真时不向 PLC 输出结果，不写正式记录；相机断线和算法异常时的判定动作已实测。
- [ ] 视觉软件崩溃时，PLC 按事先定义的动作处理，已实测。
- [ ] 配方和产品不一致时不判定；相机重连后参数读回核对；旁路有时限，旁路期间的产品标为未检测。
- [ ] 漏触发和计数不一致已实测：按 `VIS-20` 处理，重新对齐后才恢复判定。
- [ ] PLC 握手已实测：超时和写入中断时不重发，结果不会落到下一个产品。
- [ ] 最坏负载下从触发到结果在预算内；超时和丢帧的判定动作已实测。
- [ ] 磁盘将满和写入失败已实测；标准件核对可用，结果写入记录。
- [ ] 标定和配方可以备份、恢复，版本写入判定结果。
- [ ] 工控机的运行环境按部署文档核对过。
- [ ] 使用模型时：保留图像集或影子运行通过，回滚已演练。
- [ ] 浸泡测试通过，内存、句柄和丢帧计数平稳。

## 大屏

- [ ] 目标分辨率和拼接方式下显示正确，含超长名称和很大的数：没有滚动条和裁切，关键数字不压拼接缝。
- [ ] 断网、后端重启和数据过期时显示正确，恢复后不需要人操作。
- [ ] 取数失败、没有数据和数据为零显示不同；画面冻结能被外部看门狗发现。
- [ ] 断电重启、程序崩溃和系统弹窗后自动恢复，不需要人到现场；版本和运行状态可以远程查看。
- [ ] 轮播时新告警看得到，告警持续时其他页面仍能显示。
- [ ] 凭据撤销和到期时屏上显示取数失败，不显示登录页。
- [ ] 指标和来源报表核对过班次和日切换。
- [ ] 浸泡测试通过，内存、定时器、连接数和图表实例数平稳。
- [ ] 真实屏幕和实际距离下走查通过。
- [ ] 屏上内容按摆放场所核对过，展示端只读。
